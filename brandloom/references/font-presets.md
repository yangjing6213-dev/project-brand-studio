# 字体预设

字体是组合而非单一字体，公开 Skill 包不打包字体文件。预设：微软雅黑 + Segoe UI；思源黑体 + Inter；HarmonyOS Sans + Inter；阿里妈妈数黑体 + Montserrat；得意黑 + Space Grotesk。后两组仅在本机存在且许可满足时可选。

解析顺序：先使用用户选定且可显示全部文案的字体；缺字时自动尝试该字体预设的后备字体和本机其他字体；仍不完整时，从固定版本的 Noto Sans CJK SC 官方仓库下载，并校验文件哈希、保存 OFL 许可证和来源记录后，放入项目 `.brandloom/font-cache/`。不安装到 Windows 系统目录，也不放入公开 Skill 包。字体表检查覆盖所有可见字符，包括 ASCII 英文和标点；换用字体后仍需通过 Pillow 排版尺寸检查，避免文字溢出。

下载来源限定为 Noto CJK 官方仓库的固定提交；文件大小和 SHA-256 不匹配、许可证校验失败或字体无法读取时，不使用该文件，并给出具体错误。下载到本地后，后续生成复用已校验缓存。溢出时仍需调整文案或版式，不自动删改已确认文案。
