# QA 检查清单

自动化检查：输出文件存在且尺寸符合规格；PNG 可解码；manifest 的 `rendered_copy` 与 BrandBrief 完全一致；公司 LOGO 来源哈希存在且可追溯；输出路径与历史版本不冲突并使用版本号；自定义 IP 不得为 `analysis_only`；`logo_card` 角色数量不得超过已确认数量。

人工视觉检查：先检查 LOGO 主视觉的比例、字形、清晰度、构图和角色职责，再交由用户验收；用户接受后才检查封面。检查画风/字体冲突、对比度、角色数量、标题长度、真实场景抢焦点及第三方复制风险。人工检查以 warning 记录，必须明确用户复核后才能交付。

方形主视觉与封面分别核对：是否有可辨识且符合项目用途的真实环境、可信的透视/光线/材质，是否与已确认 `style.scene` 和 `style.scene_rationale` 一致；不能用纯黑、纯色、纯渐变、纯抽象背景或无关的通用办公桌替代。背景满铺且不抢文字，概念界面不能冒充实际截图。本地化应保持同一底图。该检查属于视觉语义验收，尺寸/哈希或提示词检查成功不代表已经通过；不合格时停留在对应内部 QA 阶段，返回场景/shot list 调整并重新确认，不自动再生或交付。

任一自动化检查失败都返回对应阶段并阻止 `DELIVERED`；不得通过降低断言、覆盖旧文件或自动再生来制造通过。
