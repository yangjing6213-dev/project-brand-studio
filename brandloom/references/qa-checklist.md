# QA 检查清单

## 自动化检查

- 每个输出都对应一个已确认的平台用途、语言和尺寸；实际像素尺寸与该输出规格完全一致。
- PNG 可解码且为 sRGB；输出路径与已有历史版本不冲突，并使用新版本号。
- manifest 的 `rendered_copy` 与 BrandBrief 完全一致；公司 LOGO 来源哈希存在且可追溯。
- 自定义 IP 不得为 `analysis_only`；所有上传素材都已确认使用权、保存 scope 和 default scope。
- 仅检查用户选中的封面输出，不创建或要求 1:1 LOGO 方形图。
- 生成前确认项目事实、最终文案、平台尺寸、风格参考、人物授权/穿着、标题强调色和文字区域均已收齐；多语言组先确认一张母版，再从同一底图和模板本地化。

## 人工视觉检查

对每张封面分别检查：平台用途和画幅是否正确；背景是否为贴合项目用途的真实场景；不同平台是否保留同一核心卖点，并按使用场景调整文案长度和信息量；缩略显示下项目名、核心价值是否仍清楚；关键文字是否落在平台安全区；主体是否被裁切或被界面遮挡；文案是否适合普通用户；对比度、字形、Logo 等比例、角色数量与动作是否合理；是否误用或近似复制第三方素材。

对 `stage-screen-poster` 额外检查：人物与大屏都清晰可辨；主标题在屏幕外，其他确认文案在屏幕边界内；屏幕接近正面、边框与内容面关系清楚；屏内文案的对齐、留白、字号和内容层级服从屏幕界面，不像漂浮字幕或浮在屏幕前的卡片；没有反光压住文字、随机可读字或文字越过屏幕边缘。

将同一项目的横图、竖图并排对照，确认它们共享品牌视觉，但每张都按自身画幅重新构图。将多语言图与用户已通过的母版对照：场景、主体、镜头、屏幕大小/位置、标题层级/颜色和总体间距保持一致，语言替换准确且排版不拥挤。人工视觉 warning 必须提示用户逐张复核后才能交付。

任一自动化检查失败都返回对应阶段并阻止 `DELIVERED`；不得通过降低断言、覆盖旧文件或自动再生来制造通过。平台公开规格未说明的尺寸，必须标记为建议值，并提醒用户以实际发布/预览界面为准。
另外核对真实场景：每张封面是否有可辨识且符合项目用途的环境、可信的透视/光线/材质，是否与已确认的 `style.scene`、`style.scene_rationale` 和目标专属 `scene_concept` 一致；不能用纯黑、纯色、纯渐变、纯抽象背景或无关的通用办公桌替代。背景满铺且不抢文字，概念界面不能冒充实际截图。本地化应保持同一底图。该检查属于视觉语义验收，尺寸/哈希或提示词检查成功不代表已经通过；不合格时停留在对应内部 QA 阶段，返回场景/shot list 调整并重新确认，不自动再生或交付。

任一自动化检查失败都返回对应阶段并阻止 `DELIVERED`；不得通过降低断言、覆盖旧文件或自动再生来制造通过。
