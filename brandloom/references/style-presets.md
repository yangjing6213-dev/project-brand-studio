# 主视觉风格选项

## 对话中的四个选项

四种风格都必须遵循 `composition-recipes.md` 的真实场景契约：先按项目用途确认具体环境，再应用风格；不能因选择极简、黑金或 3D 而改成纯色、纯黑、渐变或纯抽象背景。推荐项必须根据当前项目、目标读者、平台画幅和已确认文案动态选择，不得默认推荐同一风格。

主视觉 QA 只显示以下四种方案。

### 风格 A：暖色创作者桌面海报（`creator-desk-handwritten`，附件 1）

- 参考图：`.brandloom/style-reference-library/style-01-warm-creator-desk.jpg`
- 视觉特征：暖木色桌面与真实创作空间、柔和琥珀色灯光、人物自然坐在电脑前；参考图以大幅手写/笔刷感标题、白黄对比和手绘强调线作为风格参考。
- 构图可随平台调整，不机械复制原图左右位置；人物应自然融入工作场景，关键文案保持可读。
- 文字约束：最终文案由 Pillow 使用已确认字体确定性排版；当前内置字体预设不保证手写笔刷字形、手绘划线或逐词双色效果。若这些效果是必需项，用户须提供有权使用且通过字符/排版检查的字体或素材；否则应明确接受以常规可读字体近似呈现，不得承诺精准复刻附件字效。
- **人物素材必需**：用户需另行提供希望呈现的人物照片，并确认有权使用。附件 1 只作风格与构图参考，不可作为人物身份来源。

### 风格 B：演讲舞台大屏海报（`stage-screen-poster`，附件 2 + 附件 3）

- 场景参考：`.brandloom/style-reference-library/style-02-talk-stage.jpg`
- 文字与版式参考：`.brandloom/style-reference-library/style-03-bold-cover-type.jpg`
- 视觉特征：真实演讲厅/发布会舞台，深蓝或深色大屏、清晰舞台灯光；画面角度可以变化，但**主讲人物和展示大屏必须同时清晰出现**。
- 版式规则：主标题在展示大屏之外，以附件 3 的粗重字形、大字分层和强对比海报感呈现；参考图有明显深色描边/阴影时应保留这种字效，避免标题与背景融在一起。白色为标题基础色，关键词使用另行确认的强调色。除标题外的副标题、说明和卖点排在展示大屏内，版式细节见 `composition-recipes.md`。
- **人物素材必需**：用户需另行提供希望呈现的人物照片并确认有权使用。附件 2 的演讲者不能充当用户人物形象；附件 2/3 只用于场景、构图、字重和层级参考。
- **穿着必须单独确认**：可选简洁日常、休闲商务、正式演讲、科技休闲或用户自定义；需结合项目与目标读者给出有理由的推荐。不得未经确认改动用户人物照片中的身份特征。
- **强调色必须单独确认**：基础色固定白色；用户为标题关键词选择附件 3 的亮黄、项目品牌色或自定义颜色。展示具体颜色名称/色值并检查与背景的对比度；低对比时先给调整选项，不得静默改色。

### 风格 C：明亮 SaaS 产品展示（`light-saas-product-showcase`，附件 4）

- 参考图：`.brandloom/style-reference-library/style-04-light-saas-product.png`
- 视觉特征：浅色、明亮、干净的产品展示氛围；主标题与简介层级清楚，产品界面或设备屏幕作为视觉主体，周边用少量功能卡片、图标或状态信息解释价值，采用蓝色系重点和轻柔阴影。
- 结合既有“真实场景背景”要求时，将其落在明亮的真实工作/产品演示环境中；不退化成纯渐变或抽象底图。按平台缩减功能卡片和文字密度。
- 若用户要求显示真实、可读的产品界面，必须先取得该项目的实际界面截图；没有截图时只可使用不含可读功能声明的抽象界面占位结构，并由 Pillow 排入已确认的文字，不能编造功能或状态。
- 附件 4 仅提供产品展示层级参考；不照搬 ENHE 标识、产品名、按钮文案或界面细节。

### 风格 D：沿用当前项目已有风格（`project-existing-style`）

- 从当前项目已确认的品牌档案、先前通过的封面或用户明确标记为正式的视觉素材中提取风格。
- 沿用的是配色、字体气质、光线、材质、构图节奏和品牌元素，不是机械复制旧图；按当前平台重新适配画幅。
- 找不到已确认来源时，明确告诉用户目前没有可复用的项目风格证据，提供改选 A/B/C 或补充一个项目参考图的选项。不得把 BrandLoom 默认风格冒充为用户项目既有风格。

## 本地参考图库与使用边界

- 当前用户提供的四张原图保存在工作区的 `.brandloom/style-reference-library/`，该目录被 Git 忽略，供本机后续任务查看，不进入提交、ZIP 或公开发行包。
- 本地参考图库可用时，默认附带所选风格对应的图：选择 A 时使用 `style-01-warm-creator-desk.jpg`；选择 B 时同时使用 `style-02-talk-stage.jpg` 与 `style-03-bold-cover-type.jpg`；选择 C 时使用 `style-04-light-saas-product.png`；选择 D 时使用项目自身已确认的来源。
- 参考图只用于抽象风格、色彩、构图和文字层级。禁止复制或仿造参考图中的人物身份、脸部、原文案、产品界面、公司标识、平台水印和账号信息。
- A/B 的用户人物素材必须作为单独输入，与风格参考分开标记；不能因参考图中有人物，就跳过人物素材和授权确认。
- 如果发行版用户没有本地参考图，必须告知用户并展示两个明确选项：重新上传对应参考图（只在本次使用、仅抽象分析、不设默认），或按本文件文字描述继续。前者写入 `style.reference_mode: "provided"` 和 `style.reference_paths`；后者写入 `style.reference_mode: "text-only"`。不得静默略过，也不得声称能逐像素复刻或保证完全一致。

## 跨平台适配

保持选定风格的核心色彩、光线和品牌气质稳定，但针对每种平台画幅独立安排人物比例、标题层级、屏幕位置、信息量和安全区。场景底图仍需匹配目标宽高比；不得裁切、拉伸或把一张已排版完成的图硬改成其他比例。
