# 风格预设

对外顶层菜单只有三类：`reference-adaptive`（推荐）、`editorial-minimal`、`soft-3d-brand`。

所有预设用于 `logo-card` 或 `cover` 时，都必须遵循 `composition-recipes.md` 的真实场景契约。先按项目用途确认具体环境，再应用风格；不能因为选择极简、黑金或 3D 而改成纯色、纯黑、渐变或抽象背景。

`reference-adaptive` 从参考图抽象分析并选择一个主家族：

- `bright-saas-real-scene`：明亮真实使用环境、自然光、蓝紫辅助色、文案覆盖场景。
- `dark-neon-product`：深色霓虹、紫蓝光效、UI 与桌面融合。
- `high-density-commercial`：真实使用场景中的黑金配色、高信息密度、强标题与功能清单。
- `cinematic-monitor-hero`：真实办公室、中心显示器、电影感展示、大字覆盖。

除上述四个 `reference-adaptive` 主家族外，另列两个具体 profile（不增加顶层菜单数量）：`editorial-minimal-grid`（低干扰真实环境、编辑式网格与疏朗排版）和 `soft-3d-brand-icon`（写实环境中的柔和 3D 前景或 IP、轻玻璃质感；App Icon 仅作为独立标志资产）。纯项目图标的背景不受方形主视觉/封面规则约束。

附件1–6的第三方海报仅作为本地抽象风格分析参考，不是可发行素材；不得复制原图、商标、水印或打包进 Skill。记录主色、背景、场景、构图、密度、光线、标签/按钮、图标表现及明确排除的冲突特征。
